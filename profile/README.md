<h2>家庭 IP 的判定，靠三个「物理证据」</h2>
<p>标注可以改，注册信息可以洗，但有些东西改不了：数据从哪条线路出发、经过多少跳、晚高峰受不受邻居影响。这三样是物理层面的证据，也是判断一条地址是不是真家庭宽带最可靠的办法。</p>
<p>下面把三项证据拆开讲，每项说明怎么看、看到什么算家庭、看到什么算托管。</p>

<h2>证据一：ASN 与运营商名称</h2>
<p>查地址的 ASN 归属，看它是否指向面向家庭用户的宽带运营商。指向数据中心、云服务商、或者专门的托管服务商，基本可以判定不是家庭线路。</p>
<p>要注意「运营商段托管」这种中间形态：ASN 显示为运营商，但实际承载在机房。这种情况需要结合第二项证据一起看。</p>

<h2>证据二：延迟的绝对量级</h2>
<p>这是最能说明问题的一项。国内到美国西海岸的物理距离决定了往返延迟下限在一百三十毫秒左右。如果一条号称美国家庭的地址，延迟只有三四十毫秒，那出口一定不在美国本土。</p>
<p>反过来，延迟在两百毫秒上下、且波动较大，符合跨太平洋家宽的实际表现。波动大不是缺点，反而是家庭线路的特征。</p>

<h2>证据三：晚高峰的表现</h2>
<p>家庭宽带的带宽由整条城域网共享，晚高峰时邻居都在用，速度和延迟都会明显变差。机房有专门的带宽保障，晚高峰相对平稳。</p>
<p>所以测试要分时段做：白天和晚高峰各测一次，看差异。差异明显更像家庭，几乎没有差异更像托管。这一项判断有点反直觉，但很有效。</p>

<h2>补充证据：路由跳数与邻居密度</h2>
<p>家庭线路要经过接入网、城域网，跳数多、路径杂。机房路径干净规整。用路由追踪看前几跳，能感受到差别。</p>
<p>邻居密度则通过抽查同段地址的活跃度来判断。同段地址如果大量处于活跃状态，可能是被切分销售的托管资源，也可能是真实的小区宽带集中分布，需要结合其他证据一起看。</p>

<h2>为什么不能只看一项</h2>
<p>因为每项都有例外。共享地址池的 ASN 也可能是运营商，延迟也可能偏高；有些高质量托管线路的延迟反而不像机房。单项判断容易误判，三项交叉才能定性。</p>
<p>三项里有两项符合家庭特征，基本可以认为是家庭线路。三项都不符合，就不用再纠结了。</p>

<h2>检测成本有多高</h2>
<p>很低。一个查询网页加一条命令，五分钟能出结果。晚高峰那一项需要等时段，但也不需要额外工具。</p>
<p>所以「买之前测一下」几乎没有借口不做。唯一的前提是你知道该测什么。</p>

<h2>检测出来不符合怎么办</h2>
<p>在验收期内提出，附上检测结果和截图。沟通时给数据比描述现象有效得多，「ASN 指向机房、延迟只有三十毫秒」比「感觉不像住宅」有说服力。</p>

<h2>把结果记下来的价值</h2>
<p>每次检测都记一笔：地址、ASN、延迟、检测时间、结论。攒够十条之后，你手上就有了一份自己的资源画像，下次采购可以直接对照。</p>
<p>这份记录在出现争议时也很有用，它能证明「这条地址在交付时就不符合描述」。</p>

<h2>常见问题</h2>
<h3>家庭 IP 一定比托管慢吗</h3>
<p>不一定。好的家宽线路速度不差，只是波动更大。整体上托管更稳，家庭更像真人。</p>
<h3>延迟波动大是不是有问题</h3>
<p>小幅波动是家庭线路的正常特征。波动幅度超过三倍且持续一天以上，才需要排查。</p>
<h3>能不能要求供应商提供检测报告</h3>
<p>可以，但报告可以挑选。自己测一次更可靠，也更快。</p>
<h3>检测通过就一定能用吗</h3>
<p>不一定。还要看风险评分和平台实际反馈。技术属性只是一层。</p>
